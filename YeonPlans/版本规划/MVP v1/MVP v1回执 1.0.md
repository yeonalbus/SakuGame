	- 决策项：**禁止在扫描中读取 exe 内容**（PE 头 / 版本信息 / 图标）。文件名 + 大小 + 目录结构这三种零成本信号，已经足够做 §3.2 的判定
	- 意见：必须以exe、bat、zip、7z、rar作为判定标准。以目前的决策项而言极容易出现误判。但是似乎两遍式设计是指的第一遍零成本，第二遍确认后缀？需要确认语义

	- 决策项：技术栈： **Tauri v2** + Rust 后端 + Web 前端
	- 意见：本地exe为什么要做Web前端？没懂这里的技术问题。意思是本地exe本质是web套壳吗？

3. 来源：I5
	- 决策项：**中断即作废**，下次重新扫描（不做续扫）
	- 意见：
		- 准确来说应该分为：暂停、取消两种情况
			- 暂停：
				- 停止扫描当前正在处理的游戏，清除其**正在录入**的档案。并记录为断点
				- 暂停该仓库的扫描进度，不中断。点击“开始”后重新加入扫描队列中，从断点开始继续扫描
			- 取消：
				- 停止扫描当前正在处理的游戏，清除其**正在录入**的档案
				- 终止该仓库的扫描进度，点击“开始”后重新开始扫描
